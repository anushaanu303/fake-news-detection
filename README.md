# 📰 Fake News Detection Using NLP

![scikit-learn](https://img.shields.io/badge/scikit--learn-ML-orange)

![Tests](https://img.shields.io/badge/tests-pytest-green)

A Natural Language Processing project that classifies news text as **FAKE** or **REAL** based on patterns learned from a labelled dataset, with an interactive Streamlit dashboard.

> ⚠️ **Disclaimer:** This system uses machine learning patterns learned from labelled training data. Its prediction is **not independent fact-checking** and should not be treated as proof that a news article is true or false.

## ✨ Features
- CSV upload with validation (file type, required columns, missing values, duplicates, invalid labels)
- NLP preprocessing: lowercase, HTML/URL/punctuation removal, tokenization, stopword removal, optional stemming
- TF-IDF features (unigrams + bigrams), fitted on training data only (no data leakage)
- Compares **Logistic Regression**, **Multinomial Naive Bayes** and **Passive Aggressive** classifiers
- Evaluation: accuracy, precision, recall, F1, classification report, confusion matrix
- Streamlit dashboard: Home, Single Prediction, Bulk CSV Prediction, Model Performance, Dataset Explorer, About
- Model saved with Joblib (no retraining on every app launch)
- 10 Pytest tests

## 🧰 Tech Stack
Python · Pandas · NumPy · NLTK · Scikit-learn · Matplotlib · Seaborn · Plotly · Streamlit · Joblib · Pytest

## 🚀 Getting Started

```bash
git clone https://github.com/<your-username>/fake_news_detection.git
cd fake_news_detection
python -m pip install -r requirements.txt
python train_model.py
python -m streamlit run app.py
```

Open http://localhost:8501. Run tests with `python -m pytest -q`.

Train on your own data: `python train_model.py --data path/to/your.csv`

## 📊 Dataset
- CSV with columns `text` and `label` (`FAKE` / `REAL`, case-insensitive; `0` = FAKE, `1` = REAL).
- The bundled `data/sample_news.csv` is a **small synthetic dataset** (300 template-generated articles, see `scripts/generate_sample_data.py`) made only for demo and testing. Scores on it do **not** reflect real-world performance.
- For real results, use a published labelled dataset (for example ISOT Fake News or a Kaggle fake/real news dataset) and **follow its license and citation terms**.

## 📈 Results
Metrics are generated by `train_model.py` and saved to `models/model_metadata.json`; view them on the **Model Performance** page. Results depend on the dataset you train on, so run training on your own data and report those numbers.

## ⚙️ How It Works
1. Validate and clean the CSV
2. Preprocess text (lowercase → remove HTML/URLs/punctuation → tokenize → remove stopwords)
3. TF-IDF vectorization inside a scikit-learn `Pipeline`
4. Train and compare 3 models on a stratified train/test split (`random_state=42`)
5. Pick the model with the best cross-validated macro-F1 on the training split
6. Save the pipeline and serve predictions in Streamlit

## ⚠️ Limitations
- Learns writing-style patterns, **not facts**; it does not verify sources or claims
- May fail on new topics, languages, satire, or well-written falsehoods
- Can inherit bias from the training data
